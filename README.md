An image meme about an AI agent that has gone rogue: my agent moved every
meeting on the calendar to 3 AM.

`main.py` (pure Python stdlib, no Pillow) draws the meme — a robot at its
desk, a wall calendar full of red 3 AM dots, and the punchline — and encodes
the PNG by hand (zlib + struct) to `/output/entry.png` (800x800, well under
the 1 MiB gate).
